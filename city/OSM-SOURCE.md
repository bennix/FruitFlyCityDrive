# Shanghai map source

© OpenStreetMap contributors. Data licensed under [ODbL 1.0](https://www.openstreetmap.org/copyright).

Downloaded 2026-09-15 through the [official OSM map API](https://api.openstreetmap.org/api/0.6/map.json?bbox=121.451,31.217,121.489,31.241).
Bounding box: west 121.451, south 31.217, east 121.489, north 31.241 (Shanghai centre).

- `data/shanghai-api.json`: original public OSM response, with source IDs and tags.
- `data/shanghai.json`: derived database, ODbL 1.0; generated by `import_osm.py`.
- Driving roads exclude private/no-access roads and pedestrian-only ways. The largest strongly connected component is used so all selectable destinations are reachable along directed roads.
- One-way tags are enforced. Turn restrictions, lane-level geometry, conditional access, and real signal timing are not modeled.
- Road geometry is simplified while retaining shared road nodes. Coordinates use a local equirectangular projection, four metres per visual unit.
- Building footprints come from OSM. Missing heights use five storeys; heights are clamped for rendering. Multi-polygon relations are not assembled.
- Elevation is inferred from bridge/layer tags, not surveyed altitude. Signal placement uses OSM traffic-signal nodes; signal timing and zebra markings are simulated.

Rebuild the derived dataset with `.venv/bin/python city/import_osm.py`, then `npm run build`.
